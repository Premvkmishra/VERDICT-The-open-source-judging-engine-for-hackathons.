# Verdict Frontend

Verdict is a hackathon submission and judging platform built with TanStack Start, React 19, Tailwind CSS v4, and Vite.

## Development Setup

Requirements: Node.js (v18+ recommended) and npm or bun.

```sh
# Install dependencies
npm install

# Run dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port specified in terminal) in your browser.

## Available Scripts

- `npm run dev`: Starts the Vite development server.
- `npm run build`: Builds the application for production.
- `npm run preview`: Previews the production build locally.
- `npm run lint`: Runs ESLint checks.
- `npm run format`: Formats codebase with Prettier.
